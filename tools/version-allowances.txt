# Version-shaped strings that are NOT this mod's version -- see tools\lint.ps1 rule N+9.
#
# One line per allowance: <version> <repo-relative path> -- <why it is not the mod's version>
#
# Anything matching x.y.z under src\, fomod\, plugin\ or a .cpmodproj is either AiNpcVersion()
# or a line here. A fourth place to state the version therefore cannot appear quietly: the
# rule fails on a literal it has never been told about, which is the whole point of the file.
#
# The reason is not decoration. A number nobody can explain is a number nobody dares change.
